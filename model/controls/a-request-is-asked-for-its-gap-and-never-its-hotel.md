# A request is asked for its gap and never its hotel

> Whoever reads a request asks only for what the asker could not do, never which hotel it comes from, and a hotel's name the asker offers stays out of the restatement.

## How it is carried out

The Owner, in Understand, on every feature request: it reads the request as written, asks only for the gap where the request leaves it out, and restates it in the issue without the name of any hotel the asker offered.
