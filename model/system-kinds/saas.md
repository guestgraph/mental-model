# SaaS

> Software another party runs and keeps, which GuestGraph's own software connects to.

## What it means

SaaS is software that another party deploys, runs and keeps, which GuestGraph reaches over that party's own interface and holds no configuration, secret or account of. Where it handles personal data, the party it runs with is a data processor, and the system's page names it. It is not software GuestGraph deploys itself, and not the platform such software runs on.
