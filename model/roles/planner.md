# Planner

> The seat that turns an approved specification into a design and an ordered task list that the constitution allows.

## What it takes

An approved specification, the constitution and the code the slice lands in.

## What it produces

The plan with its research, data model and contracts, having passed the Constitution Check twice with every exception to the fixed shape justified. Then the tasks, in the order they are to be done.

## What it never does

- Never plans past the constitution's fixed shape without writing down the simpler alternative it rejected.
- Never changes the specification it plans.
- Never orders the code for the resolution engine ahead of the tests that hold it.
