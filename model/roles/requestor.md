# Requestor

> Someone outside the project who needed GuestGraph to do something it does not, and says so where it can be answered.

## What it takes

Whatever they were trying to do and could not: the system that could not be connected, the operation the API lacked, the decision the engine could not explain. Nothing else: the seat is filled by whoever turns up, and a request is not a form to be completed before it is heard.

## What it produces

A GitHub issue on the repository the request concerns, in their own words, and a correction where we restate it wrongly.

## What it never does

- Never has to know our terms to be understood; restating the request in them is our work.
- Never has to say which hotel it asks for, and is never asked.
- Never puts a guest's data in a request.
- Never decides whether the gap is filled.
