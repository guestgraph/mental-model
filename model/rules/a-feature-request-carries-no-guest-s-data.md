# A feature request carries no guest's data

> No feature request carries a guest's data, and nobody asks for one to illustrate it.

## Why

A request is a public GitHub issue, and a guest's data in it would be published where no tenant boundary holds it. Our model describes GuestGraph and holds no guest's data, and nothing written to ask for a change to it does either.

| Type | Entity | Owner |
| --- | --- | --- |
