# Nobody is asked which hotel a request comes from

> Nobody who asks GuestGraph for something it does not do is asked which hotel they ask for.

## Why

A request is worth what it says about what somebody could not do, and that is the same whichever hotel asked. A request is a public issue, and asking which hotel it comes from would put a customer's name where the hotel never offered it and the answer does not need it.
