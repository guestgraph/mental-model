# The model is corrected first

> Where something we publish — a page, a site, a release, an answer — disagrees with the model, the model is corrected first and the thing is rebuilt from it; nothing is released while the disagreement stands.

## Why

guestgraph.io, the MCP server and the chat draw what they say about us from a pinned commit of this model, and every page is mastered here. A page fixed by hand and left disagreeing with the model is a second source that the next build overwrites or, worse, contradicts; correcting the model first keeps one place where a fact is true.
