# See what a guest currently has

> A guest's reservations and other source objects are listed as the guest holds them now, and a caller can look up who is on a given object.

## Description

The timeline lists each source object a guest is on, in which role, decided by the newest version of that object alone, and past associations only when asked for. A source object can be read the other way round, to see which guests it resolves to. It lists what a guest has, not every record of it, so a timeline is shorter than the records behind it; it does not follow one person from one version of an object to the next.
