# How do I connect my own system?

> The feature says any system can hand its records over as they are, the value says everything the engine does is on its REST API, and the connector strategy says how a connector of one's own reads a system and submits what it finds; the decision says why a connector reads in one direction only.

## Rests on

| Type | Entity | Owner | For |
| --- | --- | --- | --- |
| feature | Submit a record from any system | | handing records over |
| value | Everything the engine does is on its API | | the API it goes through |
| strategy | One-Direction Connector Strategy | | writing a connector |
| decision | Each source system gets its own one-direction connector | | why one direction |
