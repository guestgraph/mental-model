# Does it change or delete our original records?

> One value says every record is kept exactly as its system sent it, with a guest drawn from them rather than edited into them, the other says a record that can be read is never dropped, and the connector strategy says nothing is written back into the hotel's own systems.

| Type | Entity | Owner | For |
| --- | --- | --- | --- |
| value | Store what happened, derive who it was | | kept as sent, never edited |
| value | Never drop what can be parsed | | never dropped |
| strategy | One-Direction Connector Strategy | | nothing written back |
