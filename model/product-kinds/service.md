# Service

> Software a hotel, a group or an integrator runs itself and every other system calls.

## What it means

A product of this kind is opened by whoever operates it for a hotel and called by every system that needs its answer; it holds data of its own. The GuestGraph Engine is this kind. Software that only brings data from one source system into it is Connector.
